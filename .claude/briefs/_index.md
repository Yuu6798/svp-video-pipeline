# Task Brief Index

フォーマット規約は [`AGENTS.md`](../../AGENTS.md) §1 を参照。

## 運用ポリシー

- Claude が新規 Brief を起草したら本 index に 1 行追加
- User が Codex に渡し PR が作成されたら status を `→ codex/<branch>` に更新
- PR がマージされたら status を `merged: PR #N` に更新
- マージ済の Brief は履歴として保持（削除しない）
